# unbody.io

The [Unbody](https://unbody.io) website, built with [Astro](https://astro.build) and [Tailwind CSS](https://tailwindcss.com).

## Getting Started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:4321](http://localhost:4321) to see the site.

## Scripts

| Command | Description |
| --- | --- |
| `pnpm dev` | Start the dev server |
| `pnpm build` | Build for production (static output) |
| `pnpm preview` | Preview the production build locally |
