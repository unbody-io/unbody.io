[Adapt](https://adapt.unbody.io) is an open-source Node.js library for building AI memory systems that learn and evolve over time, rather than just storing and retrieving data.

Most memory systems fail in two ways: they cannot reason across time, and they cannot adapt when data changes shape. They memorize instead of learning: a fixed structure trying to hold non-deterministic data. Adapt is my attempt to fix that.

## How it works

Adapt runs on two components. A **Brain** orchestrates the system: routing incoming data, synthesizing answers, and monitoring whether the current memory structure still covers the domain. **Neurons** are specialists. Each neuron learns one slice of the domain by observing new data, scoring it by relevance, and compressing it into understanding instead of hoarding raw records.

When the Brain detects gaps, redundancy, or overload, it reconfigures itself. It can split overloaded neurons, merge similar ones, or create new neurons for patterns it was ignoring. No schema migration. No manual reconfiguration loop.

## Learning operations

You steer Adapt with three operations:

- `inject()` feeds the Brain new observations.
- `signal()` nudges structural change when the current memory graph needs to adapt.
- `adjust()` tunes a single neuron without rewriting the whole system.

Querying is separate from learning. Questions consult accumulated neuron knowledge and return answers with relevance and confidence scores, so the system can explain not just what it knows, but how strongly each neuron contributed.
